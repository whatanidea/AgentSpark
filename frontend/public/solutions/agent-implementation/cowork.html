How we implement Claude Cowork

Each phase ends with something your team can inspect. Timing depends on access and reviewer availability.

  1. Phase 01

    Define a useful brief

    The account lead brings a past brief, the notes behind it, and the time it took to prepare. Together we choose the questions a one-page brief must answer.

    You keep   An annotated reference brief and a preparation-time baseline.

  2. Phase 02

    Prepare the evidence folder

    With the workspace admin, confirm Cowork access. Copy approved notes into a pilot folder, keep originals untouched, and use a separate destination for drafts.

    You keep   A file inventory and a tested input/output boundary.

  3. Phase 03

    Build the briefing routine

    We set the brief format: account context, requests, commitments, and open questions. Every material claim points to a filename and passage; missing evidence becomes a question.

    You keep   A reusable task instruction and an editable brief template.

  4. Phase 04

    Challenge the draft

    The lead checks a normal account, two notes with conflicting dates, and a folder missing the latest meeting. Release only if material claims are traceable and conflicts remain visible.

    You keep   A marked-up test set with errors, revisions, and sign-off.

  5. Phase 05

    Run alongside the account lead

    Compare manual preparation with draft-plus-review time for the next agreed calls. The lead owns distribution. If sources cannot be traced, revert to manual briefing.

    You keep   A team playbook, review checklist, and expand-or-stop decision.
